# Agent T — отчёт по машине TryHackMe

> **Сложность:** Easy  
> **Направление:** эксплуатация веб-сервисов, определение уязвимого ПО  
> **Лаборатория:** [Agent T на TryHackMe](https://tryhackme.com/room/agentt)  
> **Подробное прохождение:** [открыть `WRITEUP.md`](./WRITEUP.md) — содержит спойлеры

## Обзор

Agent T — небольшая лабораторная машина, посвящённая обнаружению веб-сервиса, определению версии программного обеспечения и проверке общедоступного эксплойта. Задание показывает, как точная идентификация сервиса позволяет перейти от разведки к выполнению команд на целевой системе.

## Навыки и инструменты

- Сканирование сети и определение версий сервисов
- Идентификация технологий веб-приложения
- Поиск и проверка общедоступных эксплойтов
- Nmap
- SearchSploit / Exploit-DB

## Разведка

Тестирование началось со сканирования Nmap. Был обнаружен HTTP-сервис на TCP-порту 80, а полученные метаданные позволили определить используемую сборку PHP.

## Перечисление

Веб-сервис использовал PHP 8.1.0-dev. Эта версия была проверена по базам публичных эксплойтов с помощью SearchSploit и Exploit-DB.

## Эксплуатация

Для обнаруженной версии был найден и проверен подходящий публичный эксплойт. Его успешное выполнение в учебной среде подтвердило возможность удалённого выполнения команд через уязвимый веб-стек.

## Повышение привилегий

Отдельный этап повышения привилегий в исходном отчёте не зафиксирован. Эксплуатации веб-сервиса оказалось достаточно для выполнения цели лаборатории.

## Влияние

Неаутентифицированный злоумышленник, имеющий сетевой доступ к сервису, мог выполнять команды на сервере. В зависимости от прав процесса это могло привести к раскрытию данных приложения, учётных записей и ресурсов операционной системы.

## Рекомендации

- Не использовать тестовые и development-сборки на доступных извне системах.
- Обновить PHP до поддерживаемой и полностью исправленной версии.
- Минимизировать раскрытие версий ПО в HTTP-ответах.
- Ограничить доступ к административным и тестовым сервисам доверенными сетями.
- Отслеживать аномальные дочерние процессы веб-сервера.
- Вести реестр активов и регулярно выполнять проверку уязвимостей.
