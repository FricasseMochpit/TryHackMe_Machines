## Обзор

ColddBox: Easy — Linux-лаборатория, построенная вокруг WordPress. Подтверждённая цепочка включает перечисление CMS, обнаружение слабого пароля, изменение PHP-файла темы, получение обратной оболочки и эксплуатацию системной утилиты с SUID-битом для повышения прав до root.

## Навыки и инструменты

- Полное сканирование TCP-портов
- Перечисление пользователей, тем и плагинов WordPress
- Проверка стойкости паролей
- Изменение PHP-файлов после авторизации
- Работа с обратной оболочкой и стабилизация TTY
- Поиск SUID-файлов и работа с GTFOBins
- Nmap, WPScan, Netcat, Python, `find`, GTFOBins

## Разведка

Полное сканирование Nmap обнаружило HTTP на TCP-порту 80 и SSH на нестандартном TCP-порту 4512. Анализ веб-сервиса показал, что сайт работает на WordPress.

## Перечисление

WPScan использовался для поиска пользователей и установленных компонентов WordPress. Проверка паролей с материалами лаборатории выявила действующие реквизиты пользователя `c0ldd`. В административной панели было установлено, что PHP-файлы темы доступны для редактирования.

## Эксплуатация

В шаблон темы `404.php` был добавлен код обратной оболочки. Обращение к изменённому ресурсу инициировало соединение с машиной тестировщика и предоставило оболочку в контексте пользователя веб-сервиса.

## Повышение привилегий

Перечисление SUID-файлов выявило утилиту `find` как возможный вектор повышения прав. Соответствующая техника GTFOBins сработала из исходной оболочки и предоставила привилегированную сессию. В отчёте отдельно отмечено, что изменение типа оболочки влияло на первую попытку эксплуатации.

## Влияние

Компрометация одного слабого аккаунта CMS привела к выполнению произвольного серверного кода и полному контролю root. Атакующий мог изменить сайт, получить секреты приложения, похитить данные и полностью захватить сервер.
